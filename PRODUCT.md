# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS. One document. The request named an HTML document; no framework.

## Users

Agents, and the people directing them, applying this visual language to new surfaces. Confirmed.

## Product Purpose

Bold Design is a specimen plus a user-invoked agent skill. The specimen recreates the pinned reference page. The skill makes other surfaces wear that same costume: admin dashboards, SaaS shells, blog pages, and similar UI.

Success: with the product content removed, a surface built under the skill is still recognizable as the same world as the specimen.

## Positioning

The costume transfers whole. Marketing, admin, SaaS, and reading surfaces share the ground, the type, the frames, and the one blue. They do not get a quieter operational variant.

## Operating Context

A person invokes the bold-design skill, then asks an agent to build or restyle a surface. The specimen is the visual check. DESIGN.md is the token record for this repo. The skill carries the costume so it still works in a repo that has no DESIGN.md.

## Capabilities and Constraints

- `reference.png` is the binding visual source. Live-site measurements were used only where they agreed with that image.
- The specimen repeats the reference page's visible copy because the request was a recreation. Other surfaces must not reuse that product's name, claims, or proof as their own.
- Do not invent customers, prices, benchmarks, or endorsements for surfaces the skill generates. Illustrative UI data must be labeled as such when a visitor could mistake it for fact.
- The skill is user-invoked only. Confirmed.
- Image generation is not available in the session that first built this. The specimen was code-led. That path is not stored.

## Brand Commitments

- System name: Bold Design. The specimen keeps the reference page's wording because it is a recreation, not a rebrand.
- Costume, not adaptation. Confirmed: every surface looks like the marketing page, including dashboards and articles.
- Dark ground is the costume. The reference is a dark page used as a full-bleed instrument, not a light app with a dark sidebar.

## Evidence on Hand

- `reference.png`: the pinned capture.
- No customer proof, pricing, or metrics belong to Bold Design. Figures inside the specimen belong to the recreated page.

## Product Principles

- The page is an instrument drawing, not a template.
- One blue. It is the action.
- Type does the hierarchy. Frames do the grouping.
- Show the control working. Do not describe it with an icon.
- The costume does not relax for operational software.
