/wait-what

Say we give an agent a Select component. It can build a Select. Makes sense, right?

But what if, instead, we gave it the pieces that make up a Select? The popup (createPopup), choosing from the list (createSelection), and finding an option by typing (createTypeahead).

Now not only can it build a Select, but it can build an autocomplete, a combobox or even a new component we haven’t thought of yet.

That’s UISDK.

We abstracted the complex interactions of user interfaces into reusable behaviors. And we taught agents how to build and how to use them.

Behaviors? What are those?

They are the pieces that make a component work: keyboard navigation, focus, selection, popups, drag and drop, and screen reader support.

  1. 01createRovingFocus

    Arrow keys move through a list, with one Tab stop.

  2. 02createTypeahead

    Type a few letters to jump to an item.

  3. 03createPopup

    Opens next to its button and stays on screen.

  4. 04createSelection

    Pick one or many, with Shift and Ctrl like a file manager.

  5. 05createReorder

    Sort a list with a pointer or the keyboard.

  6. 06createResize

    Resize boxes from their handles.

  7. 07createViewport

    Pan and zoom a canvas.

  8. 08createVirtualizer

    Renders only the rows you can see.

How do I use behaviors to build components?

You don’t. Ask your agent. We made them really good at it. The agent picks the behaviors it needs and puts them together in your framework.

  1. 1

    You ask your agent for a picker.

    Build me a picker for assigning a teammate to a task.

    Press Send to try it

  2. 2

    It builds one from behaviors.

    ▾
    createPopup

    Opens next to the button and closes on Escape.

    ↑↓
    createListbox

    Arrow keys or typing move from one person to the next.

    ≡✓
    createSelection

    Remembers who you picked and marks them.

    □→■
    createChange

    Tells your app who you picked.

    user-picker.ts
    const userPicker = definePrimitive({
  name: "user-picker",
  api: (context) => {
    const change = createChange(context)
    const popup = createPopup(context, { preset: popoverPreset })
    const listbox = createListbox(context, { key: "highlighted" })
    const selection = createSelection(context, {
      key: "value",
      set: (value, details) => change("value", value, details),
    })
    return { ...popup, listbox, selection }
  },
})
