# Bold Design

The costume is the marketing page. Admin, SaaS, and blog wear it whole. Density does not relax.

Specimen, when this repo is the working tree: `index.html`. Token record: `DESIGN.md`. Both are optional. This skill is enough in a repo that has neither.

## Steps

1. Read [`references/system.md`](references/system.md).
   Done when the surface plan names the ground, the display face, the one action, and the frame, using that file's tokens.

2. Read the matching recipe: [`references/admin.md`](references/admin.md), [`references/saas.md`](references/saas.md), or [`references/blog.md`](references/blog.md). No match: use the nearest, and say which.
   Done when the first viewport is described as that recipe's opening, not as a category template.

3. Build the surface. Product copy is the product's. The costume is not a license to reuse the specimen's product name, claims, or proof.
   Done when the page shows a working control in a frame, the primary action is the solid blue, and the title is display type with no eyebrow.

4. Check the refusals in `references/system.md` against the built surface.
   Done when each refusal is absent, or the user explicitly kept a named exception.
